# My First Machine Learning Model

## About the Project
This project demonstrates how to train a machine learning model using Python and Scikit-learn.

## Objective
Predict an exam score based on the number of hours studied.

## Technologies
- Python
- Scikit-learn
- Linear Regression

## How It Works
1. Prepare training data.
2. Create a linear regression model.
3. Train the model using `model.fit()`.
4. Predict a score using `model.predict()`.

## How to Run
```bash
py -m pip install -r requirements.txt
py train_model.py
```

## Example Output
```text
Predicted exam score: 70.0
```

## Note
The training data is artificial and is used for learning purposes only.
